G-Code Trainer

A desktop app that teaches CNC G-code with a live toolpath, plus a browser simulator you can run right now.

Run the simulator → Download installer

Toolpath motif — not a screenshot. Dashed is rapid, solid is a feed.

The problem

G-code is a list of moves. Until you can see the cutter path, a wrong arc is just a typo — and on a real machine it is a crash. I wanted the lesson and the picture of the tool in the same place.

What I built

G-Code Trainer is a desktop app, Electron and React, that pairs lessons with a live toolpath simulator. The page linked above is a simplified browser rebuild of that simulator. It is a demo of the desktop app, not the full lesson set.

The browser parser and animator handle:

  • G0 rapid and G1 linear feed.
  • G2 and G3 arcs using I and J offsets.
  • G20 and G21 for inches and millimeters.
  • G90 and G91 for absolute and incremental mode.
  • A step-through of the tool along the path, with rapids drawn dashed and feeds drawn solid.

The same habit shows up in the shop calculators — taper, speeds and feeds, surface speed — which run in the browser and download from Projects.

How to try it

Run the browser simulator with the sample bracket outline, or download the unsigned Windows installer. SmartScreen may warn on the installer. That is expected; choose More info, then Run anyway, if you trust the source.
